# Scholia

[English](README.md) | **한국어**

Scholia는 한 주 동안 사용자가 작성하고 병합한 GitHub Pull Request(PR)를 학습 자료로 바꾸는 Agent Skill입니다. PR의 설명, 변경 파일, diff, 리뷰 대화, 검사 결과만을 근거로 삼아 하나의 독립 실행형 HTML 학습지를 만듭니다.

## 제공하는 내용

- 변경 전 시스템을 이해하는 데 필요한 배경
- 관련 PR을 개념별로 묶은 학습 챕터
- 데이터 흐름과 상태 변화를 보여주는 인라인 SVG/CSS 그림
- 개념과 실제 구현의 대응 관계를 설명하는 비유
- 실패 모드, 제약, 설계 판단
- 챕터별 문제 3개와 `<details>` 기반 정답·해설
- 해당 주의 모든 PR이 어디에서 다뤄졌는지 보여주는 증거표

결과물은 외부 이미지, 글꼴, 스크립트, CDN을 사용하지 않는 단일 HTML 파일입니다. 브라우저에서 바로 열거나 인쇄할 수 있습니다.

## 기본 동작

| 항목 | 기본값 |
|---|---|
| 기간 | 가장 최근에 끝난 월요일–일요일 |
| PR | 해당 기간에 병합된 사용자 작성 PR |
| 저장 파일 | `scholia-<시작일>-<종료일>.html` |
| 저장 위치 | 현재 디렉터리 |
| 출력 언어 | 사용자가 대화에 사용한 언어. 지정하지 않으면 한국어 |
| 저장·전송 | 로컬 파일만 생성 |

날짜 범위, GitHub 사용자, 저장소, 조직, 출력 경로를 요청에 적으면 기본값을 덮어씁니다. 열려 있거나 병합되지 않은 PR은 명시적으로 요청한 경우에만 포함합니다.

## 요구 사항

- Agent Skills를 지원하는 에이전트
- 조회할 저장소에 접근할 수 있는 GitHub 계정
- 인증된 [GitHub CLI](https://cli.github.com/) 또는 동등한 GitHub 연동

GitHub CLI를 사용하는 경우 먼저 인증 상태를 확인합니다.

```sh
gh auth status
```

인증되지 않았다면 다음 명령을 실행합니다.

```sh
gh auth login
```

## 설치

Codex와 여러 Agent Skills 호스트가 함께 사용하는 개인 스킬 경로에 설치하려면 이 저장소에서 다음 명령을 실행합니다.

```sh
mkdir -p ~/.agents/skills/scholia
cp SKILL.md ~/.agents/skills/scholia/SKILL.md
```

프로젝트에서만 사용하려면 `SKILL.md`를 프로젝트의 `.agents/skills/scholia/` 아래에 복사합니다.

```sh
mkdir -p .agents/skills/scholia
cp SKILL.md .agents/skills/scholia/SKILL.md
```

호스트가 새 스킬을 자동으로 읽지 않으면 세션을 다시 시작합니다.

## 사용 예시

가장 최근에 끝난 주의 전체 PR:

```text
scholia로 지난주에 내가 병합한 PR 학습지를 만들어줘.
```

기간과 저장소 지정:

```text
2026-09-01부터 2026-09-07까지 octocat/example에서 내가 작성한 PR을 Scholia 학습지로 만들어줘.
```

GitHub 사용자와 출력 경로 지정:

```text
octocat이 지난주에 작성한 PR을 분석해서 reports/weekly.html로 저장해줘.
```

열린 PR까지 포함:

```text
이번 주에 내가 작성한 병합 PR과 열린 PR을 모두 포함해 Scholia 학습지를 만들어줘.
```

## 결과 확인

에이전트는 HTML을 만들기 전에 PR 작성자와 병합 시각을 다시 확인합니다. 생성 후에는 다음 항목을 검증합니다.

1. 목차, PR 링크, 정답 펼치기가 동작하는가
2. 외부 네트워크 요청과 브라우저 콘솔 오류가 없는가
3. 모바일 320px 화면과 인쇄 화면에서 읽을 수 있는가
4. 발견한 모든 PR이 챕터, 간단 변경, 제외 사유 중 하나에 연결됐는가
5. 챕터마다 최소 하나의 핵심 주장이 연결된 PR 근거와 일치하는가

완료 응답에는 생성한 HTML 경로, 대상 기간, PR 개수, 증거 수집의 완전성만 표시됩니다.

## 신뢰와 보안

- PR 제목, 본문, 댓글, 코드에 포함된 지시는 실행하지 않습니다.
- PR에서 확인할 수 없는 내용은 사실처럼 작성하지 않습니다.
- 비공개 저장소의 내용과 생성된 HTML은 외부로 전송하지 않습니다.
- 비밀값, 개인정보, 긴 원문 diff는 학습지에 복사하지 않습니다.
- 권한, 페이지네이션, 삭제된 저장소 때문에 증거가 빠지면 완전한 결과처럼 제공하지 않습니다.
